# 03-04 — QA automatizada, Excel y contratos E2E

## Objetivo

Cerrar fallos reproducibles de la calidad local: validar la firma básica de
Excel antes de `XLSX.read`, hacer que Playwright tenga specs no autenticadas
deterministas y alinear el test de imágenes con cookies `httpOnly`. Ampliar el
smoke solo con checks seguros; los flujos autenticados, aulas, Railway y UAT
quedan HUMAN/BLOCKED si no existen fixtures autorizadas.

## Tareas

1. Validar OLE/ZIP según extensión/MIME y rechazar archivos vacíos o incoherentes
   antes del parser, conservando límites actuales y sin guardar PII en logs.
2. Añadir specs Playwright públicos para shell/login/validación segura, sin
   credenciales ni mutaciones, y configurar el runner para fallar de forma
   accionable si no hay specs.
3. Corregir el test stale de `useAuthenticatedEvidenceImages` para verificar
   `credentials: include`, ampliar el smoke con el contrato público disponible y
   conservar pruebas negativas.
