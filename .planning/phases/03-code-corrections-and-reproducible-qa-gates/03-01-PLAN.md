# 03-01 — MySQL y Compose reproducibles

## Objetivo

Corregir el runner de MySQL para esperar readiness real, limpiar siempre el
contenedor temporal y hacer que Compose monte el SQL rastreado por el repositorio.
No se agregan credenciales reales ni se declara que Compose reemplaza Railway.

## Tareas

1. Reemplazar la espera fija del runner por polling acotado a `mysqladmin ping`
   o equivalente, sin imprimir la contraseña y con error accionable.
2. Cubrir éxito, timeout y limpieza mediante pruebas sin Docker real; ejecutar
   además la integración contra MySQL 8 real si Docker está disponible.
3. Corregir únicamente el path de inicialización SQL de Compose y verificar el
   diff; no inventar defaults de Brevo ni secretos ficticios.

## Verificación

```text
npm test --prefix backend -- --runInBand tests/scripts/run-mysql-integration.test.js
npm run test:mysql --prefix backend
docker compose config
git diff --check
```

El resultado debe distinguir PASS local, FAIL reproducible y BLOCKED por Docker,
Railway o credenciales externas.
