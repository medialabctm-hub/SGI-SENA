<objective>
Cerrar el hallazgo A3 (SGI-D03, movimientos) aplicando D-01 … D-04: la solicitud de movimiento requiere alcance por recurso y aplica a equipos verificados y no verificados; aprueba el Cuentadante titular (destinatario derivado como hoy) o el Administrador como respaldo; al aprobar el sistema ejecuta el traslado de forma atómica (cambia ambiente, registra movimiento y consume la autorización); y el titular que solicita mueve directo con registro en historial. Mientras 09-15 no se despliegue, las autorizaciones aprobadas antes de este PR (`Aprobada`, `fecha_uso` NULL) siguen consumibles por su solicitante vía PUT; después de 09-15, solo por el Administrador (que conserva el cambio de ambiente por PUT, D-15). Las aprobadas con este PR se ejecutan al aprobar, así que ninguna queda atascada. La alineación del formulario de solicitud para no verificados se hace en 09-13.
