# Plan 04-01 — Catálogo y navegación

## Objetivo verificable

Un cuentadante puede abrir «Equipos a mi cargo», buscar y filtrar por ambiente sin incluir equipos de otro cuentadante ni habilitaciones personales. Las mismas restricciones gobiernan total, paginación y exportación. Registrar e importar se encuentran desde la pantalla Equipos; el sidebar muestra seguimiento sin duplicar acciones.

## Contratos de datos

- `vista_inventario=inventario_total`: `Elementos.id_cuentadante = req.user.id` para Cuentadante.
- `vista_inventario=ambientes`: IDs de ambientes autorizados por servidor.
- `vista_inventario=todos`: unión autorizada actual de ambientes y responsabilidad; el filtro `ambiente` se aplica después como intersección.
- El filtro `ambiente` llega a `GET /api/equipos`; una selección vacía o no autorizada devuelve cero filas, no el catálogo completo.
- `/mis-equipos` lleva a la vista correcta sin usar `GET /api/equipos/mis-equipos/asignados` para definir el inventario patrimonial del cuentadante.
